# roblox_antiafk
ROBLOX AntiAFK Basic Tkinter Program

A basic Python program that keeps you from being kicked for inactivity in Roblox.
This program is easier to run compared to Roblox, so if you can run ROBLOX you can run this.

ROBLOX System Requirements:
Operating system	Windows 10 64-bit or Windows 11
Processor (CPU)	1.6 GHz or better
RAM	1 GB
Graphics (GPU)	DirectX 10 compatible
Storage	300 MB free space
Internet	4–8 Mbps recommended

## How to use
1. Download and extract file
2. Open roblox_antiafk.py
3. Join a ROBLOX game
4. Click start on the gui
5. Click to refocus on ROBLOX
6. Enjoy :)
